Descargar

Cada versión se publica en GitHub Releases con un SHA256SUMS.txt. Los enlaces siguientes apuntan siempre a la última versión (véase GitHub); el ejecutable de escritorio lleva la versión en su nombre de archivo y en sus propiedades.

Windows · escritorio (portable)

Un único ejecutable, sin instalación y sin dependencias instaladas por separado. Windows 10 (21H2 o posterior) o Windows 11, 64 bits; usa el entorno WebView2 incluido en Windows. Ejecútelo como administrador para escanear discos físicos.

PhoinixDR-<versión>-windows-x64-portable.exe

Windows · línea de comandos

La herramienta phoinix: inspect, verify, scan, explain, recover, con salida JSON para automatizar.

phoinix-windows-x64.exe

Linux · x86-64

Los dos ejecutables en un archivo tar. El binario de escritorio necesita WebKitGTK 4.1 (libwebkit2gtk-4.1-0, libgtk-3-0, libayatana-appindicator3-1). Los dispositivos requieren sudo.

phoinix-linux-x64.tar.gz

Compilar desde el código fuente

PhoinixDR es un espacio de trabajo de Rust con una capa de escritorio Tauri 2. La guía de primeros pasos detalla los pasos para Windows y Linux; en macOS se compila la línea de comandos, pero el acceso a dispositivos aún no está admitido.

Antes de empezar

  • Deje de usar el disco afectado. Cada escritura puede sobrescribir lo que quiere recuperar.
  • Recupere en un disco distinto. PhoinixDR rechaza un destino en el disco de origen.
  • Si la unidad está fallando, cree primero una imagen (dd, ewfacquire, FTK Imager) y trabaje sobre la imagen; PhoinixDR lee directamente imágenes RAW, E01, VHD, VHDX y VMDK.

PhoinixDR se proporciona «tal cual» y se utiliza enteramente bajo su propio riesgo. La recuperación de datos es incierta por naturaleza, y un uso inadecuado puede provocar la pérdida permanente de datos o daños. Siempre que sea posible, trabaje a partir de una copia o de una imagen de disco y recupere los archivos en un dispositivo de almacenamiento distinto. Lea el aviso legal.
